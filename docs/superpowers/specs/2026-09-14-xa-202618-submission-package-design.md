# XA 202618 最终提交资料设计

## 目标

在 2026 年 9 月 15 日截止前，基于仓库现有程序、测试日志、实机观察记录、飞控资料和《空中抓取.mp4》，形成一套可直接检查、补齐参赛人信息并提交的比赛资料。材料必须突出当前原型的真实完成度，同时明确区分已验证成果、设计方案和后续量化验证任务。

## 项目定位

项目统一表述为“面向海上风电运维的无人机机械臂协同智能作业系统原型”。当前已完成的核心成果包括无人机搭载机械臂飞行、初步空中抓取、无线主臂与无线从臂遥操作、无跳变启动、断线安全保持与恢复、有线主臂回退，以及相应的软件和固件测试。

海上风场实测、六级风验证、厘米级悬停与末端定位、缺陷识别、三维重建、视觉闭环和力控不写成已完成成果，而是作为已经规划的后续工程化工作。

## 交付结构

最终目录为 `submission/XA-202618_最终提交资料/`，包含：

1. 项目技术报告 DOCX 和 PDF，采用 A4 中文正式报告版式，正文约 20 至 30 页。
2. 算法与控制程序包 ZIP，包含可运行源码、固件、启动脚本和部署说明，排除 Git 元数据、构建缓存、WiFi 配置和全部凭据。
3. 实验数据与验证材料 ZIP，包含选定的无线、有线和恢复测试日志、证据记录、分析结果及视频关键帧。
4. 原始演示视频《空中抓取.mp4》。
5. 提交前检查清单，标明必须人工补充的报名表、姓名、单位、联系方式和签章信息。
6. 提交邮件正文和附件说明。

## 技术报告结构

报告包括封面、摘要、目录、项目背景、需求分析、总体架构、无人机飞控与搭载系统、机械臂与末端执行器、无线主从遥操作、通信协议与网络适配、安全状态机、协同控制方法、实机空中抓取验证、软件与固件测试、性能分析、海上环境适应设计、工程化与商业化、风险和迭代路线、结论及附录。

报告中的架构图、控制流程图和性能图表由现有系统结构与日志生成。视频关键帧用于展示起飞、接近目标、机械臂展开和空中抓取过程。所有图表注明数据来源和验证边界。

## 证据规则

- 《空中抓取.mp4》作为无人机搭载机械臂飞行和初步空中抓取的直接视觉证据。
- 无线遥操作日志作为命令发送、反馈、延迟、超时和拒绝计数的直接数据证据。
- 操作员确认记录作为无跳动、无异常声音、停止保持和恢复行为的观察证据。
- 自动测试与 ESP32 C3 编译结果作为软件和固件正确性的工程证据。
- 飞控资料中的 PX4、Pixhawk 和 QGroundControl 链接只用于说明技术路线，不作为性能达标证明。
- 未经测量的悬停精度、末端误差、抗风等级、识别准确率和帧率一律不填写推测数值。

## 安全与隐私

程序包不得读取、复制或打包任何 `wifi_config.h`、热点名称、WiFi 密码、访问令牌或其他凭据。硬件校准文件可以作为部署参考，但需明确其设备专属性。报告不得包含个人信息，未知字段统一使用“请填写”占位符。

## 验收标准

- DOCX 和 PDF 内容一致，逐页渲染检查无文字重叠、截断、乱码或空白异常。
- 报告中的完成度陈述均能对应现有证据或明确标注为规划。
- 两个 ZIP 可正常解压，清单清楚，不含凭据和构建缓存。
- 视频原件可播放，关键帧与报告叙述一致。
- 最终目录附有一页式提交清单，用户只需补齐身份信息和官方报名表即可提交。
